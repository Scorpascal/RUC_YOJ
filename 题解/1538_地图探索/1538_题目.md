【问题描述】

我们的主角大黄蜂在探索地图。

地图是一个n*m的网格地图。大黄蜂从左上角(1,1)位置出发，前往右下角(n,m)位置。地图分为三种方格：空地，藏宝室和陷阱。空地和藏宝室是大黄蜂可以经过的地点，而且大黄蜂经过藏宝室可以得到该藏宝室对应的奖金。大黄蜂无法经过陷阱。

每次移动，大黄蜂可以**向下**、**向右**或者**向右下**移动1个单位的距离。

请问，大黄蜂能否到达终点？大黄蜂到达终点时最多能得到多少奖金？

【输入格式】

第一行两个正整数n和m，表示地图的长和宽。

接下来m行，每行n个整数。其中第j行的第i个整数表示位置（i,j）的方格信息map(i,j)，其中：

map(i,j)=0，表示此处为空地；

map(i,j)=-1，表示此处为陷阱；

map(i,j)为正整数，表示此处为藏宝室，藏宝室的奖金等于map(i,j)的值。

【输出格式】

若大黄蜂无法到达终点，输出“No”（不加双引号）；

若大黄蜂可以到达终点，第一行输出“Yes”（不加双引号），第二行输出大黄蜂到达终点时最多能得到的奖金数量。

【输入样例1】

3 3

0 2 0

-1 3 0

0 0 4

【输出样例1】

Yes

9

【输入样例2】

4 4

0 -1 2 0

3 0 -1 4

0 -1 -1 6

-1 0 -1 7

【输出样例1】

No

【数据范围】

1 < n, m <= 500

保证（1，1）和（n，m）都不是陷阱。
