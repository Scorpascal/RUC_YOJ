问题描述

给定一个数字 N，你可以进行以下四种操作：

1. 将 N 替换为 N + 1（成本 A）

2. 将 N 替换为 N × 2（成本 B）

3. 将 N 替换为 N × 3（成本 C）

4. 将 N 替换为 N - 1（成本 D）

你的目标是用最小的总成本将 N 变成M。

额外约束：

· 操作过程中数字不能超过上限 L，也不能低于下限 0

· 需要输出具体的最优操作序列

· 可能存在负成本，但要防止无限循环

输入格式

· 第一行：两个整数 N 和 M (0≤ N, M ≤ 10^5)

· 第二行：四个整数 A, B, C, D 表示操作成本

· 第三行：整数 L 表示数字上限(M ≤ L ≤ 2×10^5)

输出格式

· 第一行：最小总成本

· 第二行：操作次数 K

· 接下来 K 行：每行一个操作描述(乘号用小写字母x表示)

例如：输入：

2 8

1 1 2 1

20

输出：

2

2

x2

x2
