设想你正在为实验室编写一个数据处理模组。

请实现一个核心函数 `analyze_experiment`，该函数能够处理多组实验数据并生成统计报告。

函数要求：

```
analyze_experiment(base_weight, observations, threshold=0.0, metadata)
```

参数说明：

`base_weight`：基础权重（浮点数）。

`observations`：接收任意数量的实验观测值（浮点数）。

`threshold`：过滤阈值。只有**大于**该阈值的观测值才参与计算。

metada参数 表示试验名称。

函数实现的计算：

```
返回结果 = (参与计算的观测值之和 / 参与计算的数量) * base_weight
```

若没有观测值满足阈值threshold条件，结果返回 `0.00`

``

输入：

第一行：一个整数 N，表示实验案例数量。

接下来 N 行，每行格式：*`实验名称 权重 阈值 观测值1 观测值2 ... 观测值M`*（数量不固定）。

输入例子（N=2）：

2

Exp_0 1.08 45.1 77.2 61.8 62.8 70.5 43.3 96.0 52.5 38.9 69.7 17.9 19.1 31.3 32.1 65.0

Exp_1 1.53 15.8 27.4 8.0 14.3 71.4 74.5 81.8 24.8 16.2

输出例子：

Exp_0: 74.99

Exp_1: 75.51
