【问题描述】

有 n ( n <= 2e6 ) 个材料需要某机器进行加工，机器一次只能加工一个材料，且必须加工完成一个材料后才能加工下一个材料。每个材料有一个时间限制，如果超过这个时间还没有加工完毕，则该材料就报废了。你需要帮助机器指定一个处理顺序以加工尽可能多的材料。

【输入格式】

第一行有一个整数 n ，表示材料数；

接下来的 n 行每行 2 个整数，分别表示加工该材料所需的时间以及该材料的时间限制

【输出格式】

一个整数表示最多加工的材料数目

【输入样例】

```
4
100 200
200 1300
1000 1250
2000 3200
```

【输出样例】

```
3
```
