## 题目描述

我们得到了两个序列 a和 b。

我们希望判断两个序列满足匹配，当且仅当存在某个数 x，使得对于所有的 i 有 a_i + x = b_i。

序列 a 旋转，即通过一次参数为 k 的旋转可以将序列 a_1, a_2, ..., a_n 变为 a_{1+k}, a_{2+k}, ..., a_n, a_1, a_2, ..., a_k。

我们希望知道，是否存在这样的旋转操作，能够让序列 a 和 b 满足匹配。

输出共一行，一个自然数 k 表示参数为 k 的旋转操作能够让 a, b 满足匹配，如果存在多个这样的 k，请输出最小的 k，如果不存在这样的 k，请输出 -1。

## 输入格式

输入的第一行包含一个正整数 n。

第二行包含 n 个正整数 a_1, a_2, ..., a_n，相邻整数之间使用一个空格分隔。

第三行包含 n 个正整数 b_1, b_2, ..., b_n，相邻整数之间使用一个空格分隔。

## 输出格式

输出一行包含一个整数表示答案，如果不存在，请输出整数 -1。

## 输入输出样例 #1

### 输入 #1

```

4

2 3 4 5

2 3 4 1

```

### 输出 #1

```

1

```

## 说明/提示

**【样例说明】**

可以让序列 a 旋转得到 3 4 5 2，根据匹配的定义，令 x = -1，那么此时 a, b 就是和谐的。

**【评测用例规模与约定】**

对于所有评测用例，1 <= n <= 5*10^5，1 <= a_i, b_i <= 10^9。
