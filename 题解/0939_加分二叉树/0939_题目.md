【问题描述】

设一个 n 个节点的二叉树中序遍历为 1, 2, ..., n， 其中每个数字为节点编号。每个节点都有一个正整数的分数 d_{i}，整颗二叉树及其每一个子树的分数计算为：

左子树的分数 * 右子树的分数 + 根节点的分数

若某个子树为空，则该子树分数计算为 1， 叶节点的分数就是其本身，不考虑叶节点的空子树。

给定每个节点的分数，试求一颗符合中序遍历为 1-n 且分数最高的二叉树，要求输出：

1）二叉树的最高分数 2）此时二叉树的先序遍历

【输入格式】

数据的第 1 行是正整数 n ( < 30)，表示节点个数。

第 2 行有 n 个整数，表示每个节点分数 d_{i}。

【输出格式】

输出共 2 行，第 1 行为最大分数(保证不超过4e9)，第 2 行为 n 个整数表示先序遍历。

【输入样例】

```
55 7 1 2 10
```

【输出样例】

```
1453 1 2 4 5
```
