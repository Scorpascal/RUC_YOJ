题目描述

给定一棵包含 n个结点的二叉树，结点编号为1,2,...,n，根结点编号为 1。已知每个结点的左孩子和右孩子编号。若一个孩子不存在，其编号为 $0$。

定义结点 u 和 v 的最近公共祖先（Lowest Common Ancestor, LCA）为：同时是 u 和 v 的祖先（结点也视为自身的祖先）、且深度最大的结点。

现有 q 次询问，每次给出两个结点 u,v，请输出它们的最近公共祖先编号。

输入格式

第一行两个整数 n,q，表示结点数与询问次数。

接下来 n 行，第 i行两个整数 l_i,r_i，分别表示结点 i的左、右孩子编号；0 表示没有对应孩子。

接下来 q行，每行两个整数 u,v，表示一次询问。

保证输入构成一棵以 1为根的合法二叉树，所有结点均可由根访问到。

输出格式

输出 q 行，每行一个整数，表示对应询问的最近公共祖先编号。

样例

输入

7 5

2 7

4 0

0 0

0 3

0 0

0 5

6 0

3 4

3 5

5 6

2 3

7 7

输出

4

1

6

2

7
