C语言数学库中用来计算x的y次幂的函数的定义如下： double pow( double x, double y)，用该函数用来做整数的幂运算不仅耗时多，结果也经常不够准确。

因此请你自己写一个计算整数x的y（y是非负整数）次幂的函数，该函数的定义如下： int power( int x, int y );
