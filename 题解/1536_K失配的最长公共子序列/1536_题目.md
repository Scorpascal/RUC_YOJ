给定两个字符串 s 和 t，以及一个整数 K。定义一对匹配为从 s 中选择严格递增的下标 i1 < i2 < ... < iL 和从 t 中选择严格递增的下标 j1 < j2 < ... < jL，使得形成长度为 L 的配对序列 (s[i1], t[j1]), (s[i2], t[j2]), ...。在这些配对中，允许最多 K 对字符不相等（称为“不相等匹配”或“容错匹配”），其余配对必须相等。请你求出在最多 K 次不相等匹配限制下，能得到的最长匹配长度 L。

当 K = 0 时，问题退化为经典的最长公共子序列（LCS）。

输入格式：

第一行：字符串 s

第二行：字符串 t

第三行：整数 K

输出格式：

一行一个整数，表示允许最多 K 次不相等匹配时的最长匹配长度。

数据范围：

1 ≤ |s|, |t| ≤ 1000

0 ≤ K ≤ 10

字符串由小写英文字母组成

样例输入1：

abcde

abXde

1

样例输出1：

5

解释：允许一次不相等匹配，将 c 与 X 作为一次不相等匹配，其余位置相等，可得到长度 5。

样例输入2：

aaaa

bbbb

2

样例输出2：

2
