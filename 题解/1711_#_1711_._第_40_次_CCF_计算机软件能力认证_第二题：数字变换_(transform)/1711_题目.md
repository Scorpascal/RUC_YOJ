小 C 设计了一种变换 F，若输入 [0, 2⁹) 中的整数，则输出也是 [0, 2⁹) 中的整数。

记 ⊕ 为按位异或运算，即 C++/Java/Python 中的 ^ 运算符。

若 x, k 均为 [0, 2³) 内的整数，定义

f(x, k) = ((x² + k²) mod 2³) ⊕ k。

若 x 为 [0, 2⁹) 内的整数，k 为 [0, 2³) 内的整数。把 x 的二进制高位补零凑成 9 位，按从高到低分成三位一组，记为高三位 a、中三位 b、低三位 c。g (x, k) 把这三组分别变换：

- 输出的高三位 = b；
- 输出的中三位 = c ⊕ f (b, k)；
- 输出的低三位 = a ⊕ f (c, k)。

记 f0 为 F 变换的输入值，并定义 fi = g (f (i-1), ki)，i = 1, 2, …, m，则 fm 为输出值。长为 m 的序列 K 是给定的参数序列，其中每个数字都在 [0, 2³) 之间。

现在小 C 有 n 个经过 F 变换后得到的值 a1, a2, …, an，他想知道它们对应的输入分别是什么。

**输入格式**

第一行两个正整数 n, m。

第二行有 m 个非负整数，分别为 k1, k2, …, km。

第三行有 n 个非负整数，分别为 a1, a2, …, an。

**输出格式**

输出一行 n 个非负整数，表示 a1, …, an 各自对应的输入。

**样例 1 输入**

```
1 2
3 5
504
```

**样例 1 输出**

```
101
```

**样例 1 解释**

枚举输入 f0 = 101。

对 f1 = g (101, 3)：a=1，b=4，c=5，c⊕f (b,3)=7，a⊕f (c,3)=0，故 f1=312。

对 f2 = g (312, 5)：a=4，b=7，c=0，c⊕f (b,5)=7，a⊕f (c,5)=0，故 f2=504。

因此输入 101 经过变换得到 504，故 101 是所求输入；枚举其他数可验证其输出不是 504。

**子任务**

- 80% 数据满足：1 ≤ n ≤ 100，1 ≤ m ≤ 20。
- 100% 数据满足：1 ≤ n ≤ 5×10⁵，1 ≤ m ≤ 10³，0 ≤ ki < 2³，0 ≤ ai < 2⁹，且只有唯一输入能得到这些输出。
