【题目描述】

给出平面上 n(<=1e6) 个点，求出能覆盖这 n 个点的最小的圆

【输入格式】

第一行为整数 n

接下来 n 行每行 2 个实数表示一个点的坐标，保证不超过双精度的范围

【输出格式】

三个实数（保留2位小数），分别表示圆心的坐标和圆的半径

【输入样例】

```
5
1.200 1.200
2.400 2.400
3.800 4.500
2.500 3.100
3.900 1.300
```

【输出样例】

```
2.50 2.85 2.10
```
