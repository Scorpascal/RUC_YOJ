【问题描述】

对于一个n * n的01方阵，每次可以交换方阵的某两行或某两列，问是否能够通过若干次交换操作，使方阵从左上到右下的这一条对角线全是1？

【输入格式】

本题单测试点内有多组测试数据。

第一行包含一个整数 T，表示数据的组数，对于每组数据，输入格式如下：

第一行为一个整数，代表方阵的大小 n。接下来 n 行每行为 n 个整数，保证为0或1。

n <= 200, T <= 20

【输出格式】

对于每组数据，输出一行一个字符串，若可以通过若干次交换满足要求则输出 Yes，否则输出 No。

【输入样例】

```
2
2
0 0
0 1
3
0 0 1
0 1 0
1 0 0
```

【输出样例】

```
No
Yes
```
