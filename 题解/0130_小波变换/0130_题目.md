小波压缩变换是信号压缩的一个普遍的工具，现有一些经过小波压缩变换后的信号，需要还原出原始信号，请你编程解决。 　　简单的小波压缩变换工作的原理如下：假设输入信号为一个整数序列，通过把信号中数成对相加或相减来计算求和信号和求异信号, 形成的求同信号序列和求异信号序列的长度均为输入信号的长度的一半。

如果输入信号序列是A={a(1)，... ，a(n)}、求同信号S={s(1)，…，s(n/2)}、 求异信号D={d(1)，…，d(n/2)} 的计算方式为：　for i = 1,...,n/2:

s(i) = a(2*i-1) + a(2*i)

d(i) = a(2*i-1) - a(2*i)

例如输入信号是： 5, 2, 3, 2, 5, 7, 9, 6

求出的求同信号和求异信号分别是： 　　s = { 7, 5, 12, 15} 　　d = {3, 1, -2, 3}

将求同信号和求异组合之后，原信号变换为: 　　A’ = {7, 5, 12, 15, 3, 1, -2, 3}

同样过程再对当前的信号A’的前半部分操作，直到输入信号的长度为1，变换过程结束。

还使用上面的例子，输入的原始信号为5, 2, 3, 2, 5, 7, 9, 6，该信号经过一系列变换后得到小波压缩变换结果为

39, -15, 2, -3, 3, 1, -2, 3，

变换过程如下 :

5, 2, 3, 2, 5, 7, 9, 6

7, 5, 12, 15, 3, 1, -2, 3

12, 27, 2, -3, 3, 1, -2, 3

39, -15, 2, -3, 3, 1, -2, 3

原始的输入信号的长度是2的整数次幂， 并且输入信号中的每个元素为0 和255 之间的整数。

输入格式

共两行，第一行，一个整数n ( 2 <= n <= 1024 )，表示输入信号的长度，n保证是2的整数次幂；第二行n个空格隔开的整数，即经过简单小波压缩变换后的信号。输入保证所求的原始信号是一个整数序列。

输出格式

共一行，n个空格隔开的整数，即你求得的原始信号。

输入样例

8
39 -15 2 -3 3 1 -2 3

输出样例

5 2 3 2 5 7 9 6
