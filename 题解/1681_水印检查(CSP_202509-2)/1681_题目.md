# 水印检查

时间限制 1 秒，空间限制 512 MiB。

### 题目描述

n×n 灰度矩阵 A 的元素在 [0,L-1]。选择整数阈值 k 后，将灰度值大于等于 k 的像素变白，其他像素变黑。检查是否存在一个 5×9 子矩阵，恰好呈现下列 CSP 水印（1 为白，0 为黑）：

```
111111111100100101100111110100001100111111100
```

不考虑旋转或翻转。请找出 [0,L-1] 内所有能够检出水印的阈值。

### 输入格式

第一行两个正整数 n、L，接下来 n 行每行 n 个整数，依次给出矩阵 A。

### 输出格式

每行输出一个可行整数阈值，按从小到大排列，每个值只输出一次。

### 完整范围与子任务

- 80% 测试点：n≤50，L=256。
- 全部测试点：9≤n≤200，L∈{256,65536}，0≤A[i](http://yoj.ruc.edu.cn/index.php/index/problem/detail/pno/1681.html#)≤L-1。
- 保证至少有一个阈值能检测出 CSP。

### 样例解释与测试边界

样例有效阈值为 4、5、7。k=4 或 5 时水印位于后五行，k=7 时位于前五行。应覆盖最小矩阵、最后一个窗口、多个不连续阈值区间、重合/包含区间、只有一个可行阈值、阈值为 1 或 L-1、宽区间。由于水印含黑格且灰度非负，k=0 不可能可行。

