Problem Title: Post-Order Traversal from Pre-Order and In-Order

Problem Description:

You are given the pre-order and in-order traversal sequences of a binary tree. Your task is to determine the post-order traversal sequence of the same binary tree.

Write a function `find_post_order(preorder, inorder)` that takes two lists of integers as input, representing the pre-order and in-order traversal sequences of a binary tree respectively, and returns a list of integers representing the post-order traversal sequence of the binary tree.

Function Signature:

```
def find_post_order(preorder: List[int], inorder: List[int]) -> List[int]:    # Your implementation here
```

Input:

- `N` (1 <= N <= 1000): number of elements
- `preorder` (1 <= len(preorder) <= 1000): A list of distinct integers representing the pre-order traversal sequence of the binary tree.
- `inorder` (1 <= len(inorder) <= 1000): A list of distinct integers representing the in-order traversal sequence of the binary tree.

It is guaranteed that the input sequences represent a valid binary tree and the input sequences are not empty.

```
5
3 9 20 15 7
9 3 15 20 7
```

Output:

A list of integers representing the post-order traversal sequence of the binary tree.

```
9 15 7 20 3
```

Example:

```
assert find_post_order([3, 9, 20, 15, 7], [9, 3, 15, 20, 7]) == [9, 15, 7, 20, 3]
```

Note:

In the given example, the binary tree can be visualized as follows:

```
    3
   /
  9  20
    /
   15   7
```

The pre-order traversal sequence is `[3, 9, 20, 15, 7]`, and the in-order traversal sequence is `[9, 3, 15, 20, 7]`. The corresponding post-order traversal sequence is `[9, 15, 7, 20, 3]`.
