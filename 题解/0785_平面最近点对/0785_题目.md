【问题描述】

给定 n 个二位欧几里得平面上的点 p_{1}, p_{2}, ... , p_{n}，请输出距离最近的两个点的距离。

【输入格式】

输入第一行为一个正整数 n ，表示点数。

接下来的 n 行，第 i 行为用空格隔开的整数 x_{i}, y_{i}，表示 p_{i} = (x_{i}, y_{i})

【输出格式】

输出一行，包含一个整数 D^{2}，表示距离最近的两个点的距离的**平方**。

由于输入的点为整点，因此这个值一定是整数。

【输入样例 1】

```
2
-10000000 -10000000
10000000 10000000
```

【输出样例 1】

```
800000000000000
```

【输入样例 2】

```
5
1 1
1 9
9 1
9 9
0 10
```

【输出样例 2】

```
2
```

【数据范围】

对于100%的数据，2 <= n <= 4 * 10^{5}, -10^{7} <= x_{i}, y_{i} <= 10^{7}
