【题目描述】

给一个$n$个节点的树（树是一个没有重边，没有环和自环的无向连通图）。

树的每一条边都有一个正整数的边权。

我们定义树上两点的距离为两点最短路径中边的最小值。

即$dist(x,y) = min_{ein path}(e_{val})$。

现在你要找到一个$1$到$n$的排列，使得$sum_{i=2}^n dist(a_{i-1},a_i)$最大。

【输入描述】

第一行，一个整数$n(2le nle 10^6)$。

接下来$n-1$行，每行三个整数$u,v,w$，表示树边$(u,v)$的权值为$w$，其中$1le u,vle n,1le wle 10^6$。

【输出描述】

一个整数，表示最大的值（不需要输出排列）。

【样例输入】

```

3

1 2 1

1 3 2

```

【样例输出】

```

3

```

【样例解释】

dist(1,2) = 1

dist(1,3) = 2

dist(2,3) = min(1,2) = 1

排列[1,2,3]的值为1+1=2

排列[1,3,2]的值为2+1=3

排列[2,1,3]的值为1+2=3

排列[2,3,1]的值为1+2=3

排列[3,1,2]的值为2+1=3

排列[3,2,1]的值为1+1=2
