### **描述**

小明学习了字符串匹配，他发现字符串匹配可以分为允许匹配重叠和不允许匹配重叠两种情况，比如字符串T="ababa"和模式串P="aba"，如果允许重叠，那么可以在T中找到两处匹配位置，而如果不允许重叠，则最多只能找到一处匹配位置(T[0...2]或者T[2...4])。

对于长度为n的字符串T，我们有n-1种方法可以将其拆分为两个不为空的字符串T1和T2（即T = T1 + T2 且 |T1| > 0, |T2| > 0）。

小明想知道，有多少种拆分方法不会减少不重叠匹配次数。

具体来说，我们定义函数g(T, P)为模式串P在字符串T中最大不重叠匹配次数，你需要输出有多少个字符串T1和T2满足：

1. T1,T2均不为空，即 |T1| > 0, |T2| > 0
2. T1,T2是T的一个拆分，即 T = T1 + T2
3. 不重叠匹配次数不减少，即 g(T1, P) + g(T2, P) = g(T, P)

### **输入**

第一行输入字符串 T。

第二行输入模式串 P。

### **输出**

输出一个整数表示有多少中拆分方法不会降低不重叠匹配次数。

### **输入样例1**

```
ababa
aba
```

### **输出样例1**

```
4
```

### **输入样例2**

```
ababa
bab
```

### **输出样例2**

```
2
```

### **限制**

1 <= |P| <= |T| <= 1,000,000
