分值: 14

给定一段文本，提取其中所有以 `#` 开头且以空格结束的话题（不含 `#`）。

统计各话题出现的频率，并按频率降序输出；若频率相同，按字母序升序输出。

输入：一段包含多个话题的字符串。

输出：每行一个话题及其频率，格式为 `话题:频率`。

*输入样例：*

```
Welcome to #Python programming! #Python is powerful. Let's study #Data and #Python today. #AI is the future. #AI #AI #Data #Coding
```

*输出样例：*

```
AI:3
Python:3
Data:2
Coding:1
```

注意：**话题必须严格以空格结尾才算作完整话题。**
