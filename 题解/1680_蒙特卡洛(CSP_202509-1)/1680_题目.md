# 蒙特卡洛

时间限制 1 秒，空间限制 512 MiB。

### 题目描述

给定正整数 a，在平面直角坐标系中画一个边长为 2a 的正方形，左下角和右上角分别为 (-a,-a)、(a,a)，再画一个以原点为圆心、a 为半径的圆。在正方形内（含边界）随机生成 n 个坐标点，统计其中落在圆内（含边界）的点数 m。圆和正方形的面积比约等于 m/n，故用 4m/n 估计 π。给定这些坐标，请输出该估计值。

### 输入格式

第一行两个正整数 n、a。接下来 n 行，每行两个数 x、y，表示一个坐标点。

### 输出格式

输出一个实数，即 4m/n。相对误差或绝对误差小于 0.0001 即可，题面推荐保留六位小数。

### 完整范围与子任务

- 50% 测试点：所有输入坐标均为整数。
- 全部测试点：0<n,a≤1000，坐标在正方形内，坐标最多两位小数。

### 样例解释与测试边界

样例 1 只有 (-5,5) 在圆外，结果为 3.0。样例 2 有三个点在圆内，结果为 2.4。边界包括圆心、圆周、正方形顶点、重复点、全部在圆内/外、n=a=1、两位小数的近圆周点。圆周必须计入。

## 样例 1

输入：

```
4 5
3 4
-5 5
0 0
3 4
```

输出：

```
3.0
```

## 样例 2

输入：

```
5 5
3.01 3.99
-5 5
0 0
2.9 4.1
-3 4
```

输出：

```
2.4
```
