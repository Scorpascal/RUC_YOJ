【问题描述】

给定两条DNA序列，请输出两条序列的最长公共子序列的长度。

【输入格式】

输入共两行，每行为一条只包含AGCT的字符串。

【输出格式】

输出一行，包含一个整数，表示两条序列的最长公共子序列的长度。

【输入样例】

```
AGCCCTAAGGGCTACCTAGCTT
GACAGCCTACAAGCGTTAGCTTG
```

【输出样例】

```
16
```

【样例解释】

最长公共子序列如加粗部分所示：

**AGC**C**CTAA**GG**GCT**ACC**TAGCTT**

GAC**AGCCTA**CA**AGC**G**T****TAGCTT**G

【数据范围】

对于100%的数据，每条序列长度 <= 1000
