输入一个华氏温度，要求输出摄氏温度。

华氏温度与摄氏温度的转换公式为C = (F - 32)*5/9 ，其中c表示摄氏温度，F表示华氏温度

# 输入格式

一个整数n(-2000 <= n <= 2000)。

# 输出格式

一个小数,保留小数点后2位，即输入对应的摄氏温度

# 输入样例

32

# 输出样例

0.00
