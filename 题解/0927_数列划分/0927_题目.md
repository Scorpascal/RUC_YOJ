【问题描述】

对于一个长度为 n (n <= 1e5) 的非负整数数列，你需要将其划分为若干段，每一段之和不能超过 m ( m <= 1e9)，问划分的段数至少为多少

【输入格式】

第一行两个正整数 n, m， 含义见上

第二行 n 个非负整数表示该数列

【输出格式】

一个整数，表示最少的划分段数

【输入样例】

```
5 6
4 2 4 5 1
```

【输出样例】

```
3
```
