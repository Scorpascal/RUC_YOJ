【问题描述】

对于无向连通图中的A、B两点，问是否存在一个除 A、B 之外的点，将其删去后A、B不再连通

【输入格式】

第一行一个整数 n，表示图中节点数，节点编号为 1 ~ n (1 <= n <= 2e5)

接下来若干行每行是两个整数 u, v 表示一条无向边，直到一行中出现两个 0 表示图描述结束；保证边数不超过 5e5

再接下来是两个整数 a, b 分别表示两个节点编号

【输出格式】

若存在这样的点，则输出编号最小的那个；否则输出 No solution

【输入样例】

```
5
2 1
2 5
1 4
5 3
2 3
5 1
0 0
4 2
```

【输出样例】

```
1
```
