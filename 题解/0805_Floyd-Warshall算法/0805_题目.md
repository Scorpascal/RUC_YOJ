【问题描述】

给定 n 个点，m 条边的有向图，求出任意两点间的最短路径长度。

【输入格式】

输入第一行为三个正整数 n, m, q ，表示图的节点数，边数和查询次数。

接下来的 m 行，第 i 行为用空格隔开的整数 u_{i}, v_{i}, w_{i}，表示图中有一条以 u_{i} 为起点，v_{i} 为终点，长度为 w_{i}的边。

再接下来的 q 行，第 i 行为用空格隔开的整数 u_{i}, v_{i}，表示询问从 u_{i} 到 v_{i}的最短路径长度。

【输出格式】

输出 q 行，每行包含一个整数，表示从 u_{i} 到 v_{i}的最短路径长度。

如果没从 u_{i} 到 v_{i}的路径，则输出 inf 。

【输入样例】

```
4 5 4
1 2 2
1 3 5
2 1 1
2 3 2
3 4 2
1 3
1 4
2 3
3 1
```

【输出样例】

```
4
6
2
inf
```

【数据范围】

对于100%的数据，2 <= n <= 100, 2 <= m <= 500, 2 <= q <= 1000, 1 <= u_{i,} v_{i} <= n, 1 <= w_{i} < 1000

数据保证图中没有重边和自环。
