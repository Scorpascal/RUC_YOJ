在计算机图形学与几何计算领域，面向对象编程是实现图形系统的重要方法。本系统要求设计一个支持 2D/3D 图形渲染与计算的框架，通过继承机制构建图形类层次结构：基类`Shape`定义图形的通用属性（名称、维度）和抽象计算方法，派生类`Sphere`（球体）、`Rectangle`（矩形）、`Cube`（立方体）实现具体图形的面积 / 体积计算，`CompositeShape`支持组合多个图形以处理复杂场景。需补全代码中缺失的构造函数初始化、虚方法实现及析构函数逻辑，确保系统满足以下要求：

1. 正确处理 2D 与 3D 图形的维度特性（如 2D 图形无体积计算）；

2. 通过多态机制实现不同图形的差异化计算；

3. 合理管理内存资源，避免内存泄漏；

4. 对非法操作（如 2D 图形调用体积计算）进行异常处理。
