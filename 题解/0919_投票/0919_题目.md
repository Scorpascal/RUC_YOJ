【问题描述】

n 名同学需要投票选出若干名代表，只有获得了全部选票的同学才能当选为代表。投票的规则如下，每个人默认为自己投一票；投票具有传递性，即如果 A 给 B 投了票，B 给 C 投了票，则自动视为 A 给 C 投了票。现在给出所有同学的票型，求能够选出多少名代表。

【输入格式】

第一行：两个用空格分开的整数 n, m (n <= 1e4， m <= 5e4)

第二行起 m 行，每行两个整数 a，b 表示 a 给 b 投了一票

【输出格式】

一个整数，表示推选出的代表数目

【输入样例】

```
3 3
1 2
2 1
2 3
```

【输出样例】

```
1
```
