读入三个字母，然后输出这三个字母。

【输入格式】

输入三个字母，相邻字母间以一个空白字符（包括空格、换行、制表符）隔开。

【输出格式】

按输入格式输出字母。

【输入样例1】

a b c

【输出样例1】

a b c

【输入样例2】

a

b

c

【输出样例2】

a

b

c
