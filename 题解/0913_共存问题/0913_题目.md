【问题描述】

在一个 n * n 方格的国际象棋棋盘上，骑士可以攻击的棋盘方格为“日”字型，即设骑士的坐标为(x,y)，若不考虑边界，则它能攻击到的方格坐标为(x-2,y+1)、(x-2,y-1)、(x-1,y+2)、(x-1,y-2)、(x+1,y+2)、(x+1,y-2)、(x+2,y+1)、(x+2,y-1)。棋盘上某些方格设置了障碍，不得放置骑士。对于给定的棋盘和障碍，计算棋盘上最多可以放置多少个骑士，使得它们彼此互不攻击。

【输入格式】

第一行有两个正整数 n 和 mm 分别表示棋盘的大小和障碍数；

接下来 m 行，每行两个正整数 x, y (1 <= x, y <= n)表示障碍的坐标

n <= 200, 0 <= m <= n^2 - 1

【输出格式】

一个整数，表示最大共存骑士数

【输入样例】

```
3 2
1 1
3 3
```

【输出样例】

```
5
```
