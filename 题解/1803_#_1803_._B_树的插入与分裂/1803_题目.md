### **题目描述**

给定一棵初始为空的 M 阶 B 树，依次插入 n 个互不相同的整数。

每次插入后，输出当前 B 树的高度以及此次插入引起的节点分裂次数。

根节点所在层的高度定义为 1。空树高度为 0。

分裂时采用 B1 中定义的中位关键码提升规则。一次插入可能引发多个节点连续分裂，每次分裂均计入答案，包括根节点分裂。

### **输入格式**

第一行两个整数 M,n。

第二行 n 个互不相同的整数，表示插入顺序。

### **输出格式**

输出 n 行。

每行两个整数，依次表示本次插入完成后的树高和分裂次数。

### **输入输出样例 #1**

输入：

```
3 7
10 20 30 40 50 60 70
```

输出：

```
1 0
1 0
2 1
2 0
2 1
2 0
2 1
```

### **说明/提示**

前三次插入时：

- 插入 10：创建根节点，树高为 1。
- 插入 20：根节点包含两个关键码，无须分裂。
- 插入 30：根节点上溢，提升 20，产生新的根节点，树高增加到 2。

当一个分裂提升关键码导致父节点也发生上溢时，必须递归处理。
