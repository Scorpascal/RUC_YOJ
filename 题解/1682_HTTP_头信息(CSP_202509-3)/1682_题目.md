# HTTP 头信息

时间限制 1 秒，空间限制 512 MiB。

### 题目描述

模拟题目规定的 HPACK 解码。每条头信息是字段名和字段值组成的键值对，输出为 `key: value`。解码器维护静态表与动态表。静态表有 S 个给定条目，编号 1 至 S，不会修改。动态表最多 D 个条目，初始为空，编号从 S+1 开始。新条目插入最前面，其他动态条目编号加一，超出容量时删除最后一个。不同条目允许字段名或整个键值对相同。

三种指令：

- `1 i`：输出编号 i 的整个条目。
- `2 0 k v` 或 `2 i v`（i>0）：前者解码字段名 k 与字段值 v，后者引用条目 i 的字段名并解码 v。输出键值对，并将其插入动态表最前面。
- `3 0 k v` 或 `3 i v`（i>0）：与 2 相同地构造并输出键值对，但不插入动态表。

字段名和字段值由大小写字母、数字组成，指令中的字符串有两种编码：

1. 普通字符串：不是以 H 开头则原样输出；以 HH 开头则删除第一个 H 后输出。
2. Huffman 字符串：形如 Hb，b 是由 0-9、a-f 组成的偶数长度十六进制串。正文按字符先后紧密连接码字，高位在前。最后一个正文字节末尾补 p 个 0（0≤p≤7），再追加一个完整字节保存 p。因此需要删除末尾两个十六进制字符所表示的计数字节，再删正文末尾 p 位。

Huffman 树用前序编码给出：叶子写 `1` 后接该叶子的字符，内部节点写 `0` 后依次写左、右子树。走左边得到码位 0，走右边得到码位 1。例如树串 `001b01c1d1a` 给出 a=1、b=00、c=010、d=011。字符串 abcd 的位串为 100010011，补零后为 10001001 10000000，再附上 00000111，得到 `H898007`。

### 输入格式

第一行 S、D。接下来 S 行每行两个字符串，给出静态表字段名和字段值。下一行给出 Huffman 树串。下一行 N，随后 N 行为上述指令。

### 输出格式

共 N 行，每行一个解码后的 `key: value`，冒号后恰有一个空格。

### 完整范围与子任务

- 20% 数据：只有表格引用指令。
- 40% 数据：只有表格引用和字面量不索引指令，且不含 Huffman 编码字符串。
- 60% 数据：有所有类型指令，字面量并索引指令数量不超过 D。
- 全部数据：1≤S≤64，1≤D≤120，1≤N≤1000，Huffman 树中字符编码长度≤8 位，字段名与字段值在解码前、后的长度均≤150。

### 样例解释与测试边界

样例依次演示静态引用、仅引用字段名、Huffman 解码、HH 转义、动态表插入和淘汰。第 10 条插入时动态表已满，先淘汰最旧条目再在最前面插入。重点测试 D=1、最新/最旧动态索引、重复字段名、2 与 3 的区别、p=0 至 7、码字跨字节、深度 8、长度上界和连续多次淘汰。
