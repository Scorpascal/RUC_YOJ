定三角形三条边的长度，求此三角形的面积。

提示：海伦公式![题面图片](http://yoj.ruc.edu.cn/Data/Ueditor/php/upload/16901584001332.png)，其中![题面图片](http://yoj.ruc.edu.cn/Data/Ueditor/php/upload/54721584001332.png)。

输入格式

三个用空格隔开的小于1000的正整数。（输入保证这三个数能够构成三角形）

输出格式

输出一个数，为所求的三角形面积，四舍五入保留2位小数。

输入样例

3 4 5

输出样例

6.00

---------------------------------------------

提示：

1. c++ cout保留小数点后5位的示例代码

#include <iostream>

#include <iomanip>

using namespace std;

int main(){

float a;

cin>>a;

cout<<fixed<<setprecision(5)<<a;

}
