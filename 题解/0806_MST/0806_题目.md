### 描述

对于一个有权无向连通图，图中的边有颜色，为蓝色或红色。现在需要求出一最小生成树，使得该生成树中恰好包含k条红色的边\(need\)

题目保证有解

## 输入格式

第一行 V，E，k 分别表示图的顶点个数，边的条数，需要的红边数\(V,E,need\)

接下来 E 行，每行代表一条边，每行 i，o，v，c 分别表示该条边的两个顶点（顶点从0开始编号），边权，颜色（0红色，1蓝色）

## 输出格式

一行，表示所求生成树的边权和。

## 样例

输入

```
2 2 1
0 1 1 1
0 1 2 0
```

输出

```
2
```

## 数据范围

对于 \(5\%\) 的数据，\(V\le 10\)

对于另 \(15\%\) 的数据，\(V\le 15\)。

对于 \(100\%\) 的数据，\(V\le 5\times 10^{4},E\le 10^{5}\)

所有数据边权为[1，100]中的正整数。
