西西艾弗岛上的居民经常使用 InkGraph 系统对图片加密。加密方把图片输入系统后可得到一份系统文件和一个对应密钥；接收方拿到系统文件和密钥输入系统，经解码后即可获得原始图片。

具体地，一张图片用一个 n 行 m 列的字符表格 P 表示，第 i 行第 j 列的字符记为 P (i,j)（1 ≤ i ≤ n，1 ≤ j ≤ m），字符仅含大小写字母、数字和下划线。新加入的小 C 学习了这个系统的加密方法。

**加密步骤**

加密一张图片 P 前，先设定整数规模参数 Z（1 ≤ Z ≤ 400）。导入 P 后，系统自动在右下方用字符？把它补齐成一张 Z×Z 的正方形图片 A0。

系统请求加密次数 t（1 ≤ t ≤ 5×10⁶）。从 A0 开始做 t 次加密，第 i 次输入 A (i-1)、输出 Ai。t 次结束后，把最终结果图 At 和密钥序列 K（一个整数序列）输出到系统文件。加密开始前，先向空密钥 K 中加入整数 t，即 K 的第一个数是 t。

第 i 次加密的类型 opi 选自 {1, 2}：

- **op i = 1，旋转加密**：生成五元组 (u, v, L, d, r)，满足 1 ≤ u, v ≤ Z，1 ≤ L ≤ min (Z, 10)，u+L-1 ≤ Z，v+L-1 ≤ Z，d ∈ {90, 180, 270}，0 ≤ r ≤ 3。从 A (i-1) 中取出第 u 到 u+L-1 行、第 v 到 v+L-1 列的 L×L 正方形子表 B，把 B 顺时针旋转 d 度后放回原位（字符本身不旋转）；再对整张图逆时针旋转 r 个 90 度，得到 Ai。完成后向 K 末尾追加 op, u, v, L, d, r 这 6 个数。例如第一次加密的参数为 (2,2,3,90,1) 时，K 形如 {t, 1, 2, 2, 3, 90, 1}。
- **op i = 2，翻转加密**：生成五元组 (u, d, l, r, o)，满足 1 ≤ u ≤ d ≤ Z，1 ≤ l ≤ r ≤ Z，1 ≤ d-u+1 ≤ min (Z,10)，1 ≤ r-l+1 ≤ min (Z,10)，o ∈ {-1, 1}。取出第 u 到 d 行、第 l 到 r 列的矩形子表 B：o=1 时把 B 上下翻转，o=-1 时把 B 左右翻转（字符本身不翻转），再放回原位得到 Ai。完成后向 K 末尾追加 op, u, d, l, r, o 这 6 个数。例如第一次加密参数为 (2,3,1,4,-1) 时，K 形如 {t, 2, 2, 3, 1, 4, -1}。

全部 t 次加密结束后，最终结果图 At 和密钥 K 输出到系统文件。

**题目描述**

现在小 C 拿到了一份系统文件，含有加密后的最终结果图 At 和密钥序列 K，需要还原出加密方导入的原始图片 P。请你帮他完成。

**输入格式**

第一行一个正整数 Z（不小于原图的长和宽）。

接下来 Z 行为最终结果图 At，每行恰有 Z 个字符，仅含大小写字母、数字、下划线和？。

接下来一行一个正整数 k，表示密钥 K 的长度；再下一行给出 k 个空格分隔的整数，表示 K。

**输出格式**

第一行输出两个空格分隔的整数 n 和 m，表示还原出的图片 P 的宽和长。

接下来输出 n 行，每行 m 个字符，仅含大小写字母、数字和下划线。

**样例 1 输入**

```
4
?Nk?
??F?
??C?
C1??
13
2 1 2 2 3 90 1 2 2 3 1 3 -1
```

**样例 1 输出**

```
2 3
CCF
1Nk
```

**样例 1 解释**

系统进行了 2 次加密。第一次为旋转加密（过程如案例所示）；第二次为翻转加密，五元参数为 (2, 3, 1, 3, -1)。

**子任务**

- 测试点 1~5：保证 opi=2 且 Z ≤ 10；
- 测试点 6~10：保证 opi=2；
- 测试点 11~15：保证 Z ≤ 10；
- 测试点 16~20：保证 Z ≤ 400。
