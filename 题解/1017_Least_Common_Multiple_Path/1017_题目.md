## Description

Given an undirected graph with N vertices and M edges (vertices numbered 0, 1, …, n-1), each edge has a weight. All weights can be decomposed into the form `2^a*3^b`. Given four parameters s, t, x, and y, please determine whether there exists a **walk** from vertex s to vertex t, such that the least common multiple of the weights on the edges traversed by the walk is `2^x*3^y`.

Note the difference between a walk and a simple path in graph theory.
 A walk is a finite or infinite sequence of edges which joins a sequence
 of vertices. It allows for revisiting vertices and edges, meaning that
the same vertex or edge can appear multiple times within the walk.

## Input

The first line consists of two integers, N and M.
The next M lines, each line represents u, v, weight.
The last line consists of four integers, representing s, t, x, and y.

## Output

Print “True” or “False”.

## Example

Input:

```
4 2
0 1 6
1 2 6
0 3 1 1
```

Output:

```
False
```

## Constraints

N < 100, M < 10000
weight < 18446744073709551616
