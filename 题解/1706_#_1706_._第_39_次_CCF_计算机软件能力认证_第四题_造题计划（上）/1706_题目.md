小 C 想到了这样一个题目：给定一棵 n 个结点的树，要求选手给每个结点分配一个权值，使得树上所有点的权值构成一个 0 到 n−1 的排列，并满足 m 条限制，每条限制形如 (x, y, v)，表示树上从 x 到 y 路径上所有点的权值构成集合的 mex 值等于 v。

小 C 已经想到了绝妙的正解做法，现在他需要你帮他写 SPJ 的核心部分。具体而言，你会接收到一棵 n 个结点的树，其中编号为 i 的点有权值 aᵢ，且 a₁, a₂, …, aₙ 构成一个 0 到 n−1 的排列。接下来你要依次检验 m 条限制，每条限制会给定树上的两个结点 x 和 y，你需要求出从 x 到 y 的简单路径上所有点的权值构成集合的 mex 值。

对于一个集合 S，mex (S) 表示最小的没有在 S 中出现过的自然数。例如：

- mex({0, 1, 2, 5}) = 3
- mex({1, 2}) = 0

### 输入格式

输入的第一行包含两个正整数 n, m，分别表示结点数和限制条数。

第二行包含 n 个正整数 a₁, a₂, …, aₙ，表示每个结点的权值。

接下来 n−1 行每行包含两个整数，表示树上的一条边。

接下来 m 行每行包含两个整数 xᵢ, yᵢ，表示一条限制。你需要求出从 xᵢ 到 yᵢ 的简单路径上所有点的权值构成集合的 mex 值。

### 输出格式

输出 m 行每行一个整数，第 i 行表示第 i 条限制所需要求的 mex 值。

### 样例

**样例 1 输入**

```
7 3
1 0 2 6 3 4 5
1 2
2 5
2 6
1 3
3 7
1 4
5 3
6 3
7 4
```

**样例 1 输出**

```
4
3
0
```

**样例 1 解释：** 树的结构为 1−2−5、1−2−6、1−3−7、1−4。

- 路径 5→3（5-2-1-3）上的权值为 {3, 0, 1, 2}，mex = 4；
- 路径 6→3（6-2-1-3）上的权值为 {4, 0, 1, 2}，mex = 3；
- 路径 7→4（7-3-1-4）上的权值为 {5, 2, 1, 6}，mex = 0。
