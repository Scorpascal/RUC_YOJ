# 输入格式

输入一行由空格分隔的整数a，b和字符c。

# 输出格式

若表达式合法，输出a，b经过c运算的结果(整数），否则输出"NO"(不包括双引号）

# 输入样例

1 1 +

# 输出样例

2

# 特殊提示

字符c只可能是+, -, *, /, %五种之一。
