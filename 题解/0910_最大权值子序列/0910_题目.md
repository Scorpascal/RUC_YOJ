【问题描述】

给定一个长度为 n 的正整数序列 a_{i}，对于其任意一个连续子序列a_{l}a_{l+1}...a_{r}，定义其权值V(l, r)为序列长度与序列中所有元素最大公约数的乘积，即 V(l, r) = (r - l + 1) * gcd(a_{l} ,a_{l+1} ,..., a_{r})。请求出权值最大的子序列的权值

【输入格式】

第一行输入n

第二行输入 n 个数 a_{1} ... a_{n}

1 <= n <= 10^{5}, 1 <= a_{i}<= 10^{12}

【输出格式】

一个数，表示最大权值子序列的权值

【输入样例】

```
5
30 60 20 20 20
```

【输出样例】

```
80
```
