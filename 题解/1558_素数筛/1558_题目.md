# 题目描述

判断输入的正整数是否为素数。

# 输入格式

一共两行，第一行一个整数，为输入正整数的个数n；第二行n个空格隔开的正整数A_{i。}

# 输出格式

一行，对于每个正整数，如果是素数则输出YES，否则输出NO，中间用空格隔开。

# 输入输出样例

| 输入#1 | 输出#1 |
| --- | --- |
| 5 1 2 3 6 18 | NO YES YES NO NO |

# 数据范围与说明

对于100%的数据，1 ≤ n ≤ 10^{6}，1 ≤ A_{i} ≤ 10^{7}。
