**题目描述**：

给定一个正整数 `n`，你需要找到所有小于等于 `n` 的素数。

**输入**：

输入一个正整数 `n`，其中 \(2\le n\le 10^{8}\)。

**输出**：

输出所有小于等于 `n` 的素数，按升序排列，每个素数占一行。

**示例**：

输入：

```
10
```

输出：

```
2
3
5
7
```
