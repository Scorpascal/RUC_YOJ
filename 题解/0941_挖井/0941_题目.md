【问题描述】

某条路上沿路有 n 个按序排列的村庄，政府决定在其中的 m 个村庄挖井以满足群众的用水需求。已知所有相邻村庄的距离，选择在哪些村庄使挖井才得所有村庄到最近水井的距离总和最小，计算该最小值。

【输入格式】

第 1 行正整数 n, m ( m <= n <= 500 )

第 2 行有 n - 1个整数，表示相邻村庄的距离( <= 100)。

【输出格式】

‍一个整数，表示各村庄到最近水井的距离之和最小值

【输入样例】

```
10 2
3 1 3 1 1 1 1 1 3
```

【输出样例】

```
18
```
