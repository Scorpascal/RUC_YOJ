# 造题计划（下）

时间限制 1 秒，空间限制 512 MiB。

### 题目描述

准备比赛的 n 天里，小 C 每天上午最多造一道题，小 F 每天下午最多验一道题，也可以选择不工作。题目必须先造出才能验，同一天上午造的题可以在当天下午验。第 i 天造题花 a[i] 精力，验题花 b[i] 精力。两人的总花费不超过 m，求最终造完且验完的最大题数。

### 输入格式

第一行 n、m。第二行 n 个正整数 a[i]，第三行 n 个正整数 b[i]。

### 输出格式

输出最多能完成的题数。

### 样例解释与测试边界

样例在第 1、4 天造题，第 2、4 天验题，花费 3+2+2+3=10，不超过 12，最多完成 2 题。边界包括一天、预算不足一题、预算足够全部题、费用相同引起平局、只有提前造/延后验便宜、反向顺序的陷阱、交错费用、预算恰等于/差一达到最优费用，以及需要 64 位运算的最大数据。
