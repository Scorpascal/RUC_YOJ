【问题描述】

给定 n 个二位欧几里得平面上的点 p_{1}, p_{2}, ... , p_{n}，请输出x轴坐标在[x_{0}, x_{1}]，y轴坐标在[y_{0}, y_{1}]内的点的数量。

【输入格式】

输入第一行为一个正整数 n ，表示点数。

接下来的 n 行，第 i 行为用空格隔开的整数 x_{i}, y_{i}，表示 p_{i} = (x_{i}, y_{i})

接下来的一行为一个正整数 q，表示查询次数。

接下来的 q 行，每行为4个用空格隔开的整数 x_{0}, x_{1}, y_{0}, y_{1}，表示查询范围。（输入保证有 x_{0} <= x_{1} ，y_{0} <= y_{1} ）

【输出格式】

输出q行，每行包含一个整数 m_{i} ，表示第 i 个查询范围内点的数量。

【输入样例 1】

```
7
1 0
3 0
0 1
2 1
4 1
1 2
3 2
4
0 1 0 1
0 2 0 1
1 3 1 2
2 3 1 2
```

【输出样例 1】

```
2
3
3
2
```

【数据范围】

对于100%的数据，2 <= n, q <= 10^{5}, 0 <= x_{i}, y_{i} < 2^{31}
