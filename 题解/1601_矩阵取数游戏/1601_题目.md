原神启动队先构建了一个N*M的原始矩阵X（每个元素为小于P的非负整数），并计算出每个2*2子矩阵的和，得到和矩阵S（S[i][j]表示以原始矩阵第i行第j列元素为右下角的2*2子矩阵的和，且S的第一行、第一列元素均为 0）。

现在需要你完成两个任务：

1. 根据给定的和矩阵S，还原出原始矩阵X，若存在多个解，输出“字典序最小”的（字典序比较：先比行数最小的不同位置，行数相同比列数最小的位置，该位置值小的矩阵字典序更小）；

2. 用还原出的原始矩阵X玩矩阵取数游戏：每次从每行取一个元素（只能取该行的行首或行尾），共取M次取完所有元素。第i次取数的得分是“每行取数的元素值 × (2^i)”之和，总得分是M次取数得分的总和，求最终的最大总得分。

已知输入的和矩阵S保证有解，且原始矩阵元素均小于P。

输入格式

第一行包含三个正整数N、M、P（分别表示原始矩阵的行数、列数、元素取值上限）；

接下来N-1行，每行包含M-1个非负整数，代表和矩阵S；

注：和矩阵S的行号、列号均从 1 开始。

输出格式

第一部分：输出还原后的原始矩阵，共N行，每行M个整数，相邻整数用空格分隔（行尾无多余空格）；

第二部分：输出一行整数，代表矩阵取数游戏的最大总得分。

输入输出样例

输入

3 3 3

4 5

5 3

输出

0 0 2

2 2 1

1 0 0

82
