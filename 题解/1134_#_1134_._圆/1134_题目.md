【题目描述】

给定平面上 \([原题字符待核对]n\)个圆和 \([原题字符待核对]m\) 个点。要求在平面上画一个半径不超过 R 的圆，使得它不包含这 n 个圆中的任何圆，也不与这 n 个圆中的任何圆相交，且包含的点个数最多。求最多包含点的个数。

【输入格式】

第一行3个非负整数 n, m, R

接下来 n 行每行三个整数 xi, yi, ri 分别表示每个圆的坐标和半径。保证这些圆不相交（可能相切）

接下来 m 行每行两个整数 pi, qi 分别表示第 i 个点的坐标

【输出格式】

一行一个整数，表示所画的半径不超过 R 的圆中最多包含点的个数

【输入样例】

```
1 5 3
0 0 1
3 3
-3 3
3 -3
3 0
0 3
```

【输出样例】

```
3
```

【数据范围】

0 <= n <= 10

0 < m <= 1000

1 <= R, ri <= 2e4

所有输入坐标的绝对值不超过2e4
