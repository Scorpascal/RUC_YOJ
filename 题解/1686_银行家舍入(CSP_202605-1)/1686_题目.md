# 银行家舍入（rounding）

时间 1 秒，空间 512 MiB。

### 题目描述

输入 n 个非负实数，每个数恰好保留一位小数，格式为 `xxx.x`。整数部分为非负整数 a，小数部分为一位数字 b（0～9），即使 b=0 也不会省略。对每个数分别计算四舍五入和银行家舍入得到的整数。

四舍五入：b≤4 时结果为 a，b≥5 时为 a+1。

银行家舍入（向偶数舍入）：b≤4 时为 a，b≥6 时为 a+1；b=5 时，若 a 为偶数则为 a，否则为 a+1。

### 输入格式

第一行正整数 n，接下来 n 行，每行一个上述格式的实数。题面建议用字符串读取，避免浮点解析误差。

### 输出格式

两行，每行 n 个空格分隔的整数。第一行是四舍五入结果，第二行是银行家舍入结果。

### 范围与子任务

- 50% 数据：不存在 b=5，两种舍入方法结果相同。
- 全部数据：1≤n≤100，0≤a≤100000，0≤b≤9。

### 样例解释与测试边界

样例最后一个数 2026.5 四舍五入为 2027，银行家舍入为 2026。覆盖 0.0、0.5、奇数/偶数整数部分加 .5、.4/.6、a=100000 进位到 100001、最小 n 与最大 n。

## 样例 1

输入：

```
47.50.013.92026.5
```

输出：

```
8 0 14 20278 0 14 2026
```
