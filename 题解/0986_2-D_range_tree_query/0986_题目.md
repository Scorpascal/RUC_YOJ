【问题描述】

假设当前有n个点散落在二维平面上, 现在给定m个查询范围[x0, x1]∩[y0, y1], 给出该范围内点的个数

【输入格式】

输入第一行为一个正整数 n ，表示点数。

接下来的 n 行，第 i 行为用空格隔开的整数 xi, yi, 表示该点的坐标.

接下来的一行为一个正整数 m，表示查询次数.

接下来的m行，每行为4个用空格隔开的整数 x0, x1, y0, y1.

【输出格式】

m行，每行包含一个整数, 表示该查询范围内点的个数.

【输入样例 】

```
7
1 0
3 0
0 1
2 1
4 1
1 2
3 2
2
1 3 1 2
2 3 1 2
```

【输出样例 】

```
3
2
```

【数据范围】

0 < n, m < 1e5+5, x0 < x1 ，y0 < y1, 0 < xi, yi < 231
