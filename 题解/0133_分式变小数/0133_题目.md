对于给出的两个整数N、D，输出分数N/D的小数形式，其中N为分子，D为分母。

如果这个小数是有循环节的, 用一对括号把循环节括起来进行表示。

例如： 1/3 = .33333333...就表示为 0.(3),

而 41/333 = 0.123123123...就表示为0.(123).

用xxx.0 来表示一个为整数的结果。

下面是几种常见的情况： 　　1/3 = 0.(3) 　　22/5 = 4.4 　　1/7 = 0.(142857) 　　2/2 = 1.0 　　3/8 = 0.375 　　45/56 = 0.803(571428)。

输入格式

一行两个数字，N和D，1 <= N，D <= 100000。

输出格式

一行，按照给出的要求输出分数N/D的小数形式。

输入样例

45 56

输出样例

0.803(571428)

特殊提示

1、 通过大家在数学分析课上的学习，大家应该知道，p/q的结果绝对是有理数。
　　2、 当结果为整数时，记得在输出时输出小数点后一位，即xxx =〉xxx.0
