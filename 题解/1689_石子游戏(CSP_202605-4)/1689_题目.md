# 石子游戏（nim）

时间 1 秒，空间 256 MiB。

### 题目描述

有 m 个仓库编号 1～m。小 S 先手，两人轮流选择一个非空仓库，将正数个石子移动到编号小一的仓库；从仓库 1 取出的石子直接丢弃，不能操作者输。题目直接给出：小 C 必胜当且仅当所有奇数编号仓库的石子数异或为 0。

给定 n 个仓库石子数 b[1]～b[n]。子游戏 (l,r) 把该段重新编号为 1～r-l+1，因此判定时使用 b[l] xor b[l+2] xor ...。每次给出 [L,R]，将它完整划分成若干非空连续段，最大化其中小 C 必胜的段数；其他段可以不必赢。

### 输入输出

第一行 n、q。第二行 n 个非负整数 b[i]。随后 q 行每行 L、R，1≤L≤R≤n。

输出 q 行，每行最大必胜段数。

样例数组 1,2,1,0，必胜子游戏只有 (1,3)、(1,4)、(4,4)。[2,3] 答案 0，[1,4] 选 (1,3) 与 (4,4)，答案 2。覆盖全 0、全相同非零值、最大 31 位值、周期异或、稀疏 0、L=R、奇偶起点、只在后缀出现获胜段、重复询问和最大输入输出。
