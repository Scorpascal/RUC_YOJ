奥运志愿者的选拔工作正在如火如荼的进行中。为了选拔最合适的人才，A市对所有的报名者进行了笔试，笔试成绩达到面试分数线的选手可以进入面试。我们根据最终录取人数的150%划定分数线，即如果有最终需要m名志愿者，则面试分数线为保证前m*150%（下取整）的人进入面试最低分数，最终进入面试的选手为笔试成绩不低于面试分数线的所有选手。 　　现在就请你编写程序划定面试分数线，并输出进入面试的选手的报名号和笔试成绩。

输入格式

第一行，两个空格隔开的整数n ( 5 <= n <= 5000)、m（5 <= m<= n），其中n表示参加笔试的选手总数，m表示可以最终要录取的志愿者人数。
　　第二行到第n+1行，每行两个整数，分别是选手的报名号k（1000 <= k <= 9999）和该选手的笔试成绩s（0 <= s <= 100）。

输出格式

第一行，两个空格隔开的整数，第一个整数表示面试成绩线，即可以进入面试的最低笔试分数；第二个整数为进入面试的选手人数。
　　从第二行开始，每行空格隔开的两个整数，为进入面试的选手的报名号和笔试成绩，按照笔试成绩从高到低输出，如果成绩相同则先输出报名号小的。

输入样例

6 3
1000 90
3239 88
2390 95
7231 84
1005 95
1001 88

输出样例

88 5
1005 95
2390 95
1000 90
1001 88
3239 88

特殊提示

【样例说明】
　　m*150% = 3*150% = 4.5，下取整后为4。保证4个人进入面试的分数线为88，因为88有重分，所以所有成绩为88的选手都可以进入面试，故最终有5个人进入面试。
