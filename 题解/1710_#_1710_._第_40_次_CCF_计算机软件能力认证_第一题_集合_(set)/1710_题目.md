小 C 现在有 m 个询问，第 i 个询问给出两个非空不可重的正整数集合 Si 和 Ti，集合中元素均在 [1, n] 内。小 C 需要回答每个询问给出的两个集合是否相等。

小 C 采取了如下做法：首先生成一个长度为 n 的非负整数序列 a1, a2, …, an。然后定义函数

f (S) = 把 i 属于 S 的所有 ai 按位异或起来（即 ai1 ⊕ ai2 ⊕ …），

其中 ⊕ 为按位异或运算，即 C++/Java/Python 中的 ^ 运算符。

如果第 i 个询问给出的集合满足 f (Si) = f (Ti)，那么小 C 便认为这两个集合相等。

现在小 C 给出了他生成的序列 a。你需要判断，对于这 m 个询问，小 C 的做法能否得到正确答案：正确输出 correct，否则输出 wrong。

**输入格式**

第一行两个正整数 n, m，表示集合内元素的值域和询问个数。

第二行给出 n 个非负整数，表示 a1, a2, …, an。

接下来 m 行，每行描述一个集合 Si。每行先给出一个正整数 |Si|，表示集合大小；接着给出 |Si| 个正整数，为该集合内的元素，保证按严格递增顺序给出。

接下来 m 行，每行描述一个集合 Ti。格式同上。

注意：本题先输入所有询问中的集合 S，再输入所有询问中的集合 T。

**输出格式**

输出 m 行，第 i 行输出 correct 或 wrong。

**样例 1 输入**

```
5 3
1 2 3 0 4
1 3
2 3 4
2 3 5
2 1 2
2 1 2
2 3 5
```

**样例 1 输出**

```
wrong
wrong
correct
```

**样例 1 解释**

第一个询问：|S1|=1，|T1|=2，大小不同则集合必不相等；但 f (S1)=a3=3，f (T1)=a1⊕a2=3，故做法错误。

第二个询问：两个集合最小元素不等，故不相等；但 f (S2)=a3⊕a4=3，f (T2)=a1⊕a2=3，故做法仍错误。

第三个询问：两集合元素一一对应相等，故相等；且 f (S3)=a3⊕a5=7，f (T3)=a3⊕a5=7，故做法正确。

**子任务**

- 50% 数据满足：|Si| ≠ |Ti|。
- 100% 数据满足：1 ≤ n ≤ 10⁴，1 ≤ m ≤ 100，0 ≤ ai <2³¹，1 ≤ |Si|, |Ti| ≤ 10³，元素均为 [1, n] 内整数。
