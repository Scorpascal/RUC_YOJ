【问题描述】

在一款战争游戏中，每局对战由两名玩家来争夺 n 个要塞，每场对战中每名玩家都有 m 个士兵， 玩家可以派遣 a_i 名士兵攻打第 i 座要塞，但每名士兵只能参加一座要塞的进攻任务中。如果一名玩家向第 i 座要塞派遣的士兵数严格大于对方的两倍，则该玩家占领这座要塞并获得 i 分。

现在你即将和 k 位其他玩家两两对战，这 k 场对战的士兵派遣方案必须相同，假设你已知其他所有玩家的士兵派遣方案，则你能获得的最大分数是多少？

【输入格式】

数据的第 1 行三个正整数 k, n, m 表示除你以外的玩家总数，要塞数以及每名玩家拥有的士兵数 (k, n <= 100, m <= 20000)

接下来 k 行每行有 n 个整数，表示某名玩家的士兵派遣方案。

【输出格式】

一个非负整数，表示你能获得的最大得分。

【输入样例】

```
2 3 10
2 2 6
0 0 0
```

【输出样例】

```
8
```
