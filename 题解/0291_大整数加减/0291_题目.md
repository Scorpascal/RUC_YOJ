比利经常会碰到超大整数的加减法运算，而普通的计算器上无法进行。因此他想你帮他写一个程序来计算结果。

# 输入格式

输入共三行。 　　第一行为一个符号，表示要进行的计算（“+”表示要进行加法运算，“-”表示要进行减法运算）。 　　第二行第三行每行为一个大整数（长度小于2000），表示要进行加减操作的两个数。注意：整数既可以为正数也可以为负数。

# 输出格式

加减运算后的结果。

# 输入样例

+

998877665544332211

11223344556677

# 输出样例

998888888888888888

# 特殊提示

输入样例2

-

-8776655443322

-91223344556677

输出样例2

82446689113355

输入样例3

+

998877665544332211

112233445566778899

输出样例3

1111111111111111110
