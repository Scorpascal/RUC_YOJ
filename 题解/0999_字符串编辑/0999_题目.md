# 题目描述

请实现一种数据结构来支持如下字符串修改查询操作

- 1. 对于给定的字符串，从指定位置p插入字符串s。
- 2. 对于给定的字符串，从指定位置p开始删除长度为l的子串。
- 3. 对于给定的字符串，从指定位置p_{1}开始复制长度为l的子串，并插入位置p_{2}处
- 4. 对于给定的字符串，查询指定位置p开始长度为l的子串中字符c出现的次数

对于以上的所有修改操作(操作1、2、3)，在修改字符串的同时需要记录版本号，对字符串执行的第i次修改操作得到的结果记为该字符串的第i个版本。

在上述查询修改操作的基础上，该数据结构还需要支持如下操作

- 5. 对于给定的字符串，将字符串回退到指定的版本i

# 输入格式

输入包含n+1行

其中第一行表示对于字符串的总操作次数

接下来n行依次输入对于字符串的操作

其中，字符串初始为空串并记为版本0

插入操作的格式为 i p s，表示从指定位置p插入字符串s。

删除操作的格式为 e p l，表示从指定位置p开始删除长度为l的子串。

复制操作的格式为 c p_{1} l p_{2}，表示从指定位置p_{1}开始复制长度为l的子串，并插入位置p_{2}处

查询操作的格式为 q p l c，表示查询指定位置p开始长度为l的子串中字符c出现的次数

版本回退操作的格式为 j i，表示回退到版本i

# 输出格式

对于每个查询操作输出一行，表示该查询操作的结果

最后输出一行，表示最后一次操作后得到的字符串 （注：最后一次操作可能为非修改操作，例如如版本回退操作）

# 数据范围

50%的数据满足, n <= 1e2, 插入的总字符串不超过1e3, 任意时刻字符串的总长度不超过1e3.

100%的数据满足，n <= 1e4, 插入的总字符串不超过1e5, 任意时刻字符串的总长度不超过1e4.

# 样例输入

5

i 0 abcd

e 0 1

c 1 2 3

q 1 4 c

j 2

# 样例输出

2

bcd

# 样例解释

操作1, "" -> "abcd"

操作2, "abcd" -> "bcd"

操作3, "bcd" -> "bcdcd"

查询, 答案为2

回退至版本2, "bcdcd" -> "bcd"
