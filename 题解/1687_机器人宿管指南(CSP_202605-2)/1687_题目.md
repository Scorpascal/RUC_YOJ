# 机器人宿管指南（apple）

时间 0.5 秒，空间 512 MiB。

### 题目描述

第 0 天有 n 个苹果。从第 1 天开始，每天先有 k% 的苹果变质：若前一天剩余 t 个，则当天先丢弃 ceil(t*k/100) 个。然后每个机器人吃一个苹果。要求所有机器人连续 m 天每天都能吃到一个苹果，每天食用结束后剩余数量≥0。第 m+1 天是否还能吃不影响答案。求最多可入住多少个机器人。

### 输入输出

输入一行三个正整数 n、k、m。输出一个正整数，为最大机器人数量。

### 范围与子任务

- 80% 数据：n≤10000。
- 全部数据：1≤n≤10^18，1≤k≤5，1≤m≤2000。
- 保证答案是一个不大于 10^9 的正整数。所有生成数据必须同时满足这条保证。

### 样例解释与测试边界

样例 1 输入 1000、1、5，答案 194，每天变质 10、8、6、4、2 个，食用后剩余 796、594、394、196、0。195 人无法撑过第 5 天。

样例 2 输入 19、5、3，答案 5，第 3 天结束后剩 1 个。覆盖 m=1、m=2000、k=1/5、恰好吃完、最后剩余、需要向上取整、n=10^18、答案 1 与 10^9。

## 样例 1

输入：

```
1000 1 5
```

输出：

```
194
```

## 样例 2

输入：

```
19 5 3
```

输出：

```
5
```
