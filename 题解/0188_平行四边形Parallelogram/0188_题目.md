给出平行四边形三个顶点的坐标，请你求出所有可能的第四个顶点的坐标。

# 输入格式

三行，每行两个用空格隔开的整数x_i,y_i，分别表示三个点的坐标， -1000≤x_i,y_i≤1000 。数据保证三个点都不同并且不在同一条直线上。

# 输出格式

第一行输出共有几个可能的第四顶点坐标，接下来每行输出一个可能的第4个顶点坐标。

# 输入样例

0 0

1 0

0 1

# 输出样例

3

1 -1

-1 1

1 1
