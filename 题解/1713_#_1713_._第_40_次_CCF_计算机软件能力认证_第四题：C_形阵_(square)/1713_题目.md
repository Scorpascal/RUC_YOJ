小 C 在西西艾弗大学担任研究员。今天他遇到一个优美的数阵，让作为助手的你帮他做些计算。

**题目描述**

小 C 把这个数阵称为 C 形阵。数阵的七个数 (A, B, C, D, E, F, G) 满足：

1. A, B, C, D, E, F, G 都是正整数；
2. A / B = B / C（即 B² = A・C）；
3. E / F = F / G（即 F² = E・G）；
4. A × B × C = C × D × E = E × F × G。

按下图摆成字母 C 的形状（上排从左到右 C B A，中排最左是 D，下排从左到右 E F G）：

```
C B A        1 2 4        2  6 18
D            2            36
E F G        4 2 1        3  6 12
            (C 形阵一)    (C 形阵二)
```

小 C 定义这个 C 形阵的**大小为 B，价值为 D**。

若集合 {A, B, C, D, E, F, G} 中恰有 6 个互不相同的元素（即七个数字里有两个相等），则称这个 C 形阵是**完美的**。以上面两个为例，C 形阵一不是完美的，C 形阵二是完美的。小 C 通过掷硬币决定是否研究完美的 C 形阵。

具体地，给你两个整数 op, n：

- op = 0：求所有大小不超过 n 的 C 形阵的价值总和；
- op = 1：求所有大小不超过 n 的完美的 C 形阵的价值总和。

答案对 998244353 取模。

**输入格式**

一行两个整数 op, n，含义同上。

**输出格式**

输出一个正整数，表示所求价值总和。

**样例 1 输入**

```
0 2
```

**样例 1 输出**

```
25
```

**样例 2 输入**

```
1 4
```

**样例 2 输出**

```
64
```

**样例 2 解释**

列举所有符合条件的 C 形阵，总价值为 32 + 32 = 64。

- 子任务二（20 分）：op = 0，n ≤ 10⁵；
- 子任务三（30 分）：n ≤ 10⁵；
- 子任务四（10 分）：op = 0；
- 子任务五（10 分）：无特殊限制。

全部数据满足：op ∈ {0, 1}，1 ≤ n ≤ 10⁷。
