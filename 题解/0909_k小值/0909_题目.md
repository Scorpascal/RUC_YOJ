【问题描述】

给定 n (1 <= n <= 4 * 10^{6}) 个整数(保证不超过int类型范围)，求出其中第 k 小 (1 <= k <= n) 的数

【输入格式】

第一行输入n, k

第二行输入 n 个数

【输出格式】

一个数，表示这 n 个数中第 k 小的数

【输入样例】

```
5 1
4 3 2 1 5
```

【输出样例】

```
1
```
