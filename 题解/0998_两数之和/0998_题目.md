## 题目描述

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

You can assume that each input has at most one solution, and you cannot use the same element twice. If there is no solution, output -1.

You must output the answers in ascending order.

## 输入格式

The first line consists of two integers separated by a space, 'n' and 'target'.

The second line contains 'n' integers separated by spaces, representing the elements inside the array.

Constraints:

2 <= nums.length <= 10^4

-10^9 <= nums[i] <= 10^9

-10^9 <= target <= 2*10^9

## 样例

输入:

```
2 6

3 3
```

输出:

```
0 1
```

输入:

```
4 26

2 7 11 15
```

输出

```
2 3
```

输入:

```
3 999999937

1 2 3
```

输出

```
-1
```
