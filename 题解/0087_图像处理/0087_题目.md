图片在计算机中也是转化为数字表示的，基本原理是：一副图片上有若干个点，每个点的颜色用R（red)、G（green）、B（blue）三种基本颜色的强度来表示。

现在小明拍了一张美丽的照片，并把它贴在了寝室的门上面。遗憾的是，他明发现照片上有一些地方脏了，经过仔细认真的侦查后小明终于找到了原因，原来是小明的单反镜头上有点问题。精通photoshop的小明决定用计算机来修复这张得意的照片。

照片上的坏点是指"R 0 G 0 B 0"点。

照片需要经过若干轮修复，直到没有可以修复的坏点为止。每轮修复，将坏点的颜色修复为其相邻的非坏点(当前这一轮刚刚被修复的点在本轮仍算坏点)的平均颜色。注意：1)相邻的点指该点上下左右的点；2)平均颜色是指相邻非坏点R、G、B的各色的平均值（向上取整）。3)如果某坏点相邻的点都是坏点的话，那么该坏点此轮无法修复。

例如下面这张图片共有5*5个点（每个格子表示图片上的一个点，其中的数字是表示该点的颜色），其中有9个坏点（涂色的格子）。9个坏点中，第一轮可以修复8个坏点（涂橘色的格子）

【输入格式】

第1行两个整数，分别表示照片的行数n(3<=n<=100)和列数m (3<=m<=100) 。

第2行到第n+1行，每行有m个点的颜色表示，每个点的颜色用R x1 G x2 B x3 的形式表示(0<=x1,x2,x3<=255) 。同行的数字和字母中间有1个空格。

【输出格式】

共n行，每行有m点的颜色表示，每个点的颜色用R x1 G x2 B x3的形式表示， (0<=x1,x2,x3<=255) ，同行的数字和字母中间有1个空格，表示处理后的照片。
