# 造题计划（上）

时间限制 1 秒，空间限制 512 MiB。

### 题目描述

给定 n 个节点的树，节点 i 的权值为 a[i]，全部权值构成 0 至 n-1 的排列。对于每个查询 x、y，求 x 到 y 的简单路径上所有节点权值组成集合的 mex，即不在集合中的最小非负整数。例如 mex({0,1,2,5})=3，mex({1,2})=0。

### 输入格式

第一行 n、m。第二行 n 个整数 a[1] 至 a[n]。接下来 n-1 行每行两个整数，表示一条树边。接下来 m 行每行 x、y，表示一次查询。

### 输出格式

共 m 行，每行一个整数，为对应路径的 mex。

### 完整范围与捆绑子任务

每个子任务必须通过其中所有测试点才得分。

| 子任务 | 分值 | 限制 |
| --- | --- | --- |
| 1 | 20 | n,m≤1000 |
| 2 | 20 | 树是一条链 |
| 3 | 30 | n,m≤50000 |
| 4 | 30 | 无特殊限制 |

全部数据：1≤n,m≤200000，权值为 0 至 n-1 的排列。

### 样例与测试边界

样例三条路径的 mex 为 4、3、0。边界包括 n=1、x=y、路径不含 0、LCA 是端点/根、全树为路径时 mex=n、任意编号的链、星形树、完全二叉树、随机树。递归 DFS 在最大长链上需要足够栈空间。

## 样例 1

输入：

```
7 3
1 0 2 6 3 4 5
1 2
2 5
2 6
1 3
3 7
1 4
5 3
6 3
7 4
```

输出：

```
4
3
0
```
