给定期末总评成绩，计算所得的学分绩点。

| 百分制 | 等级制 | 绩点 |
| --- | --- | --- |
| 90－100 | A | 4.0 |
| 86－89 | A- | 3.7 |
| 83－85 | B+ | 3.3 |
| 80－82 | B | 3.0 |
| 76－79 | B- | 2.7 |
| 73－75 | C+ | 2.3 |
| 70－72 | C | 2.0 |
| 66－69 | C- | 1.7 |
| 63－65 | D+ | 1.3 |
| 60－62 | D | 1.0 |
| 考查课合格 | P | 1.0 |
| 60分以下或者考查课不合格 | F | 0 |

输入格式

一个0~100的整数，代表期末总评成绩

输出格式

输出所得学分绩点。严格按照表中的格式输出。

输入样例

59

输出样例

0
