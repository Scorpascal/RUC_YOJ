【题目描述】

你需要维护一个排名系统，每位角色可以上传自己的分数，得分越高排名越靠前。当两个角色名次相同时先上传分数的优先。

你需要应付三种请求：上传一条新的得分记录、查询某个角色的当前排名、返回某个区段内的排名记录。当某个角色上传自己最新的分数时，他原有的分数会被删除。

【输入格式】

第一行一个整数n（10<=n<=3e5）表示待处理的请求数。接下来n行每一行表示一条请求，格式如下：
1）`+Name Score` 上传分数记录。`Name` 表示角色名，由大写英文字母组成，不超过 \(10\) 个字符。`Score` 为最多 \(10\) 位的正整数。

2）`?Name` 查询角色排名，保证已上传。

3）`?Index` 返回自第 `Index` 名开始的最多 \(10\) 名角色名字，保证合法

【输出格式】

对于每条请求输出相应结果

对于2），输出一个整数表示角色当前排名

对于3），在一行中一次输出不超过10名角色的姓名，用一个空格分割

【输入样例】

```
20
+ADAM 1000000
+BOB 1000000
+TOM 2000000
+CATHY 10000000
?TOM
?1
+DAM 100000
+BOB 1200000
+ADAM 900000
+FRANK 12340000
+LEO 9000000
+KAINE 9000000
+GRACE 8000000
+WALT 9000000
+SANDY 8000000
+MICK 9000000
+JACK 7320000
?2
?5
?KAINE
```

【输出样例】

```
2
CATHY TOM ADAM BOB
CATHY LEO KAINE WALT MICK GRACE SANDY JACK TOM BOB
WALT MICK GRACE SANDY JACK TOM BOB ADAM DAM
4
```
