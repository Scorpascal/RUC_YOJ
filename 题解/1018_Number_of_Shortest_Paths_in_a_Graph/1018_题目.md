**Problem Description**

Given an undirected unweighted graph with *N* vertices and *M* edges, where vertices are numbered from 1 to *N*. Starting from vertex 1, find the number of distinct shortest paths to every other vertex.

**Input Format**

The first line contains two positive integers *N* and *M*, representing the number of vertices and edges in the graph.

The next *M* lines contain two positive integers *x* and *y*, indicating there is an edge from vertex *x* to vertex *y*. Note that self-loops and multiple edges might be present.

**Output Format**

Output *N* lines, each containing a non-negative integer. The *i*-th line should represent the number of different shortest paths from vertex 1 to vertex *i*. Due to the possibility of large answers, output the results modulo 100003. If it’s impossible to reach vertex *i*, output 0.

**Example**

*Input*

```
5 7
1 2
1 3
2 4
3 4
2 3
4 5
4 5
```

*Output*

```
1
1
1
2
4
```

*Explanation* There are 4 different shortest paths from 1 to 5, namely 2 paths 1 → 2 → 4 → 5 and 2 paths 1 → 3 → 4 → 5 (due to 2 edges between 4 and 5).

**Constraints**

For 20% of the data, *N* ≤ 100.

For 60% of the data, *N* ≤ 1000.

For 100% of the data, 1 ≤ *N* ≤ 100000, 0 ≤ *M* ≤ 200000.
