【题目描述】

有 n 堆石子，第 i 堆石子有 a_{i} 个，最多取 m 堆石子（保证 m <= n），请问在要求总石子数不超过 k 的情况下最多能取多少石子。

【输入格式】

第一行输入三个数字 n, m, k，意义见上。

第二行 n 个数字，依次表示 a_{i}。

【输出格式】

输出一个数字，表示你的答案。

【输入样例】

4 3 5

1 1 2 3

【输出样例】

5

【数据范围】

数据分为A，B，C三组

对于 A 组数据，1 <= m <= n <= 10,1 <= k <= 1000,1 <= a_{i} <= 100；

对于 B 组数据，1 <= m <= n <= 20,1 <= k <= 10^{8},1 <= a_{i} <= 10^{6}；

对于 C 组数据，1 <= m <= n <= 200,1 <= k <= 2500,1 <= a_{i} <= 50；

30\%、30\%、40\%
