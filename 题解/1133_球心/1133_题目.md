【题目描述】

对于一个在 n 维空间中的球体，现在你只知道球面上 n+1 个点的坐标，需要你确定这个 n 维球体的球心坐标

【输入格式】

第一行是一个整数 n (<=10)。接下来的 n + 1行，每行有 n 个实数，表示球面上一点的 n 维坐标。每一个实数精确到小数点后6 位，且其绝对值都不超过20000。

【输出格式】

一行，依次给出球心的 n 维坐标（ n 个实数），两个实数之间用一个空格隔开。每个实数精确到小数点后3位。数据保证有解。

【样例输入】

2

0.0 0.0

-1.0 1.0

1.0 0.0

【样例输出】

0.500 1.500
