【问题描述】

在一个圆形操场的四周摆放 n 堆石子，现要将石子有次序地合并成一堆，规定每次只能选相邻的两堆合并成新的一堆，并将新的一堆的石子数，记为该次合并的得分。试设计出一个算法,计算出将 n 堆石子合并成 1 堆的最小得分和最大得分。

【输入格式】

数据的第 1 行是正整数 n ( n <= 200 )，表示有 n 堆石子。

第 2 行有 n 个整数，表示每堆石子的个数。

【输出格式】

输出共 2 行，第 1 行为最小得分，第 2 行为最大得分。

【输入样例】

```
44 5 9 4
```

【输出样例】

```
4354
```
