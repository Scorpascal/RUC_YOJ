【问题描述】

数轴上有 n ( n <= 1e6 ) 条线段，要求在它们之中选取 k 条线段使得这 k 条线段两两不重合，求最多能选多少条线段

【输入格式】

第一行一个整数 n

接下来 n 行每行两个整数表示线段的左右端点

【输出格式】

一个整数，表示 k 的最大值

【输入样例】

```
3
0 2
2 4
1 3
```

【输出样例】

```
2
```
