在一个神奇的国度，含有字母a或者A的单词总是有美好的含义。而最长的单词则代表了最美好的事物。所以，国王希望你能够帮助他在任意给定的一本书里面找到含有a或者A的最长的单词。

# 输入格式

输入为一行，包含了这本书中所有的单词。单词以空格隔开。不排除两个单词中有多个空格，或者头尾有空格的情况。

# 输出格式

输出只有一行，为本书中最长的含有a或者A的单词。若任何单词都不含有a或者A，则输出-1.

# 输入样例

This is a wonderful place

# 输出样例

place

# 特殊提示

输入样例2：

I like him

输出样例2：

-1

注意：一本书中最多含有200个单词，每个单词最多含有50个字符。两个单词长度相同，则输出先出现的单词。
