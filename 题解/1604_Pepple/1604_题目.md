题目描述

给定正整数 n，初始时有 n 堆石子，每堆恰有一颗。定义一次操作：选择两 堆，从它们中取出相同数量的石子，形成新的一堆。求在进行一定次数的操作后（操作次数不做限制），非空堆的个数的最小值。

输入格式

第 1 行包含一个整数 T，代表数据组数。第 2 至 T + 1 行每行一个整数 n，代表 n 堆石子。

输出格式

共 T 行，每行一个整数，代表非空堆个数最小值。

样例输入

2

3

4

样例输出

2

1

样例解释

当 n = 3 时：初始状态为 [1,1,1]。第一步合并前两堆 1，得到 [1,2]，此时无 法继续合并，最终非空堆个数为 2。

当 n = 4 时：初始状态为 [1,1,1,1]。第一步合并第 1、2 堆 1 得到 [2,1,1]；第 二步合并后两堆 1 得到 [2,2]；第三步合并两堆 2 得到 [4]，最终非空堆个数为 1。

数据范围

对于 40% 的数据，保证 n = 2^k (k ∈ N +)

对于 100% 的数据，保证 T ≤ 100，n≤ 10^18
