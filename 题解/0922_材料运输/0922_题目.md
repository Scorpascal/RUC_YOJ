【问题描述】

有 n(n <= 1e6) 个工厂在一条环路上，每个工厂有 a_i 单位的材料。每个工厂只能向相邻的两家工厂运输，每家工厂每次运输一单位材料的代价为 1 。求使所有工厂获得均等材料的最小代价。

【输入格式】

第一行有一个整数 n ，表示工厂个数；

在接下来 n 行中，每行一个整数 a_i。

【输出格式】

输出使所有工厂获得均等材料的最小代价。

【输入样例】

```
4
1
2
5
4
```

【输出样例】

```
4
```
