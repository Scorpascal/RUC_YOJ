十进制计数系统是由10个数字组成（0123456789,组成计数系统的数字由小到大排列）,想像一下你现在发现了一个由一些字符组成的外星人的计数系统，可能与十进制的相同也可能不相同，例如,如果外星计数系统表示为“oF8”（即该计数系统用3个符号表示，o是其中最小的字符）那么在这个计数系统中的1到10将被表示为：F,8,Fo,FF,F8,8o，8F,88,Foo,FoF；再比如二进制计数系统表示为"01",即该系统中所有数字都由字符0,1组成，二进制系统中的1到10被表示为：1,10,11,100,101,110,111,1000,1001,1010。 　　每一种外星计数系统都被表示为一行字符，字符按照其表示的数字从小到大的顺序排列，并且每一个字符都不重复出现。外星计数系统中的字符可以是以下字符： 　　0～9这9个数字，大小写字母，还可以包含下面的字符 !"#$%&'()*+,-./:;<=>?@[]^_`{|}~ 　　你的任务是将任意一种外星计数系统中的数字转化为另外一种外星计数系统的数字。

输入格式

共N+1行，第一行包含一个整数N(1<=N<=100)，表示共有N个不同计数系统的数字需要进行转换。
　　接下来的N行，每行描述的一个待转化的数字。
　　每行的格式如下：
　　alien_number source_language target_language
　　其中，alien_number表示待转换的数字(以source_language的形式给出），source_language表示alien_number的原始的计数系统，ttarget_language表示alien_number要转换成的目标计数系统。
　　例如：9 0123456789 oF8 表示将计数系统"0123456789"(即十进制)下的数字9转换为计数系统"oF8"中的数字。
　　注意：
　　1. 保证alien_number的第一个字符不能是source_language中的最小的字符（就好象十进制中的100我们不会写成0100一样）。
　　2. alien_number转化成十进制数的范围是：大于等于1小于等于1000000000。
　　3. source_language中的字符个数大于等于2小于等于94。
　　4. target_language中的字符个数大于等于2小于等于94。

输出格式

共N行，其中第i行表示第i+1行输入要求的转换结果（即target_language计数系统下的数字）。
　　每一行输出结果之前需要输出"Case #x: ",其中x是一个整数，代表第x个待转换的数字。

输入样例

4
9 0123456789 oF8
Foo oF8 0123456789
13 0123456789abcdef 01
CODE O!CDE? A?JM!.

输出样例

Case #1: Foo
Case #2: 9
Case #3: 10011
Case #4: JAM!

特殊提示

Case #1: 十进制数9转化为oF8计数系统下的数是Foo
　　Case #2: oF8计数系统下的数oF8转化为十进制数是9
　　Case #3: 十六进制数13转化为二进制数是10011
　　Case #3: O!CDE?计数系统下的数CODE转化为A?JM!.计数系统下的数是JAM!
