【问题描述】

任何一个正整数都可以用 2 的幂次方表示，例如137 = 2^{7}+2^{3}+2^{0} ，同时约定方次用括号来表示，即 a^{b}可表示为 a(b)，由此可知137可以表示为2(7) + 2(3) + 2(0).

进一步，7 = 2^{2}+2+2^{0}， 3 = 2+2^{0}，所以最后 \(137\)137 可表示为：2(2(2) + 2 + 2(0)) + 2(2 + 2(0)) + 2(0). 现在给你一个正整数 n ,请根据上述要求给出它的0, 2表示

【输入格式】

一个整数 n (1 <= n <= 10^{5})

【输出格式】

一行字符串, 为 n 的0, 2表示(注意表达式中不能有空格)

【输入样例】

```
1315
```

【输出样例】

```
2(2(2+2(0))+2)+2(2(2+2(0)))+2(2(2)+2(0))+2+2(0)
```
