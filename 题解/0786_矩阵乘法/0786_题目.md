【问题描述】

给定一个 n * m 的矩阵 A 和一个 m * p 的矩阵B，求矩阵乘法 C = A * B 的结果。

【输入格式】

输入第一行为三个正整数 n, m, p ，表示两个矩阵的大小。

接下来的 n 行，第 i 行为用空格隔开的 m 个整数 a_{i,1}, a_{i,2}, ... , a_{i,m}，表示矩阵 A 中第 i 行的元素。

再接下来的 m 行，第 i 行为用空格隔开的 p 个整数 b_{i,1}, b_{i,2}, ... , b_{i,p}_{}，表示矩阵 B 中第 i 行的元素。

【输出格式】

输出 n 行，每行包含 p 个整数 c_{i,1}, c_{i,2}, ... , c_{i,p}，表示矩阵 C = A * B 中第 i 行的元素。

【输入样例 1】

```
2 3 2
1 2 3
4 5 6
1 2
3 4
5 6
```

【输出样例 1】

```
22 28
49 64
```

【输入样例 2】

```
3 4 5
1030 -118 1977 -1019
1546 -55 298 -25
906 880 1429 1337
1545 -1737 768 -1653 -708
-897 -1898 376 56 1008
-1015 864 1195 1190 522
1391 1566 -1122 706 596
```

【输出样例 2】

```
-1726888 -1452772 4252505 -75982 -423514
2100660 -2362690 1550808 -2221648 -1009352
1019742 84436 1234229 1196094 1788382
```

【数据范围】

对于100%的数据，2 <= n <= 100, -2000 <= a_{i,j}, b_{i,j} <= 2000
