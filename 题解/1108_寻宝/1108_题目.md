【题目描述】

给出一个n*m的网格图，其中某些格子有若干财宝，每次从左上角出发，只能向下或向右走，每一次经过一个格子最多只能捡走一块财宝，最少走多少次才能把财宝都捡完？

【输入格式】

第一行为正整数 T，代表数据组数。

每组数据第一行为正整数 N, M 代表网格图有 N 行 M 列，接下来 N 行每行 M 个非负整数，表示此格子中财宝数量，0代表没有

【输出格式】

输出一个整数，表示至少要走多少次。

【输入样例】

1

3 3

0 1 5

5 0 0

1 0 0

【输出样例】

10

【数据范围】

1 <= T <=5, 1<= N, M <= 10^3,每个格子的财宝不超过10^6块
