人大有四位同学可能做了好事不留名，表扬信来了之后，校长问这四位是否做了好事。

A说：我没做好事。

B说：C做了好事。

C说：D做了好事。

D说：C胡说。

输入空格分隔的四位整数，分别代表A-D四位同学是否做了好事（1代表做了好事，0代表没有），输出说真话的同学的人数。

输入样例1：

1 0 0 0

输出样例1：

1

样例1解读：输入说明A做了好事，B-D没有，那么A说的假话，B说的假话，C说的假话，D说的真话，共1人说了真话。

输入样例2：

1 1 0 0

输出样例2：

1

样例1解读：输入说明A、B做了好事，C、D没有，那么A说的假话，B说的假话，C说的假话，D说的真话，共1人说了真话。
