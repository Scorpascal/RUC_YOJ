【题目描述】

考察平衡二叉树（AVL）的插入和删除操作，AVL树中不存在值相同的节点。

【输入格式】

第一行，一个整数 n，表示操作的次数。

接下来 n 行，两个整数 a 和 b。当 a = 1 时，表示向 BST 中插入一个数 b；当 a = 0 时，表示从 BST 中删除一个数 b。

【输出格式】

一行，m 个数，m 表示经过 n 次操作后剩余的节点数量。请按照先序遍历输出 AVL 各个节点的值，以空格分隔。

【输入样例】

4

1 1

1 2

1 3

0 3

【输出样例】

2 1
