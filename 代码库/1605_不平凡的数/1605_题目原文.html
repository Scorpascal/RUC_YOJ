    #1605. 不平凡的数

    内存限制：256MiB 时间限制：1000 ms 标准输入输出
    题目类型：传统 评测方式：文本比较
    上传者： youwei
    提交记录 讨论

    题目描述

    题目描述

    如果一个正整数 NN 能够被表示成 x2−y2x2−y2 的形式（x,yx,y 都是 非负整数），则称 NN 是不平凡的。

    给出 TT 个正整数，请判断这 TT 个正整数是不是不平凡的。

    输入格式

    第一行一个正整数 TT；

    接下来 TT 行，每行一个正整数 NN，表示一次查询。

    输出格式

    输出共 TT 行，每一行代表一次询问的结果。对于每次询问，如果 NN 是不平凡的，输出 YES，否则输出 NO。

    输入输出样例 #1

    输入 #1

    3
2
3
4

    输出 #1

    NO
YES
YES

    说明/提示

    【样例解释】

    3=22−123=22−12，4=22−024=22−02。

    【数据范围】

    对于 30%30% 的数据，1≤N≤50001≤N≤5000；

    对于 60%60% 的数据，1≤N≤1061≤N≤106；

    对于另外 20%20% 的数据，NN 是奇数；

    对于 100%100% 的数据，1≤T≤1051≤T≤105，1≤N≤1091≤N≤109。
