    #285. 链表操作（加入节点）

    内存限制：256MiB 时间限制：1000 ms 标准输入输出
    题目类型：传统 评测方式：文本比较
    上传者： sunh 编译环境: cpp
    提交记录

    题目描述

    【问题描述】

    编写 程序完成 单链表的 三种 基本操作 ，三种操作的命令如下：

    C n m

    在链表第 n个节点之后创建一值为 m的链表节点 ，如果 n为 0则表 示在头创建 ，显然第一次操作的 n=0 n=0；

    D n

    在链表中删除第 n个节点 ，数据 保证 该节点 是存在 的；

    P n

    输出链表中第 n个节点的值 ，数据保证该 节点 是存在 的。

    打印的函数已给出

    【输入格式】

    第一行，包含个 正整数 K，表示操作的个数。

    接下来的 K行，每表示一个操作按照描述的格式给出。

    【输出格式】

    若干行 ，每一次 P操作，输出一行。

    【样例输入】

    5

    C 0 1

    C 1 2

    P 1 

    D 1 

    P 1

    【样例输出】 

    1 2

    【数据规模】

    K <= 1000


    本题需要补充在链表中插入节点的代码。

    链表节点的定义如下：

    struct node{
        int m;
        node *next;
    };
