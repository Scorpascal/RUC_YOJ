    #1371. 实现多项式类

    内存限制：256MiB 时间限制：1000 ms 标准输入输出
    题目类型：传统 评测方式：文本比较
    上传者： 20210129 编译环境: cpp17
    提交记录

    题目描述

    在数学中，多项式是由一个或多个项组成的代数表达式，每个项包括一个系数和一个变量的指数。在计算机科学中，我们可以使用类来表示多项式，并通过运算符重载、函数指针等技术对其进行操作。

    本题要求你实现一个 Polynomial 类，支持多项式的加法、减法、求值、输出等功能，并通过运算符重载和函数指针进行动态调用。

    1. 多项式加法：

      • 重载 + 运算符，实现两个多项式的加法。

      • 多项式相加时，如果次数不同，应当按次数较大的多项式为标准，较小次数的多项式补齐为 0。

    2. 多项式减法：

      • 重载 - 运算符，实现两个多项式的减法。

      • 多项式相减时，同样需要考虑补齐较小次数的多项式。

    3. 多项式求值：

      4. 实现一个 evaluate 成员函数，根据给定的 x 值计算多项式的值。例如，若多项式为 P(x)=3x2+2x+1P(x) = 3x^2 + 2x + 1，求 P(2)P(2)时，计算结果为 3⋅22+2⋅2+1=173 cdot 2^2 + 2 cdot 2 + 1 = 17。

    4. 输出运算符重载：重载 << 输出运算符，使其能以标准格式输出多项式。

    5. 使用函数指针：

      • 定义一个函数指针类型，动态调用多项式的加法或减法运算。

      • 通过函数指针实现对多项式加法的调用。
