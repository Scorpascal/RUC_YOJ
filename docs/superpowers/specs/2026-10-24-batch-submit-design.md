# 纯网页批量提交

用户已确认：最多选择 10 题，一次确认后间隔 3 秒依次发起提交，结果仍到 YOJ 查看。无需扩展、代理或后台登录服务。

## Approaches

- 采用：沿用原生跨站表单，复用一个结果窗口。无需安装；只能记录浏览器请求发起，不能读取跨站登录态、是否受理或 Accepted。
- 未采用：YOJ 浏览器助手，可读取逐题响应，但需要额外安装和权限；用户已选择纯网页方案。

## 范围和约束

- 主页支持跨分页/筛选选择，最多 10 题；独立批量页显示题号、语言、提交形态和原站链接，确认之前不发送评测。
- 只接受公开清单中与目录 PUBLIC_READY、已复验状态一致的题目；源码以 SHA-256 核对，预加载全部通过才允许开始。
- 普通题使用 pid/language/code；单填空题使用 pno/compiler/codes。保留题目 eno 链接；不推测或绕过原站课程/考试权限。
- 固定间隔 3 秒、单窗口串行。可停止未发起部分；关闭窗口或本地异常即停止，已发起请求不可撤销。
- 每个批次只能启动一次；发送前在本标签页 sessionStorage 记录题号，刷新不自动恢复，也不自动重发不确定请求。只存题号，不存代码、账号、密码或 Cookie。
- 明示“已请求发起”不等于“原站受理/Accepted”；浏览器仍可能要求用户确认 HTTPS 到 HTTP 的提交。
- 不修改原有单题提交、AC、发布证据、脱敏或定时更新流程。

## 验收

自动测试覆盖 0/10/11 题、重复/未知/未发布题、来源和哈希失败、两种表单、eno、3 秒节流、重复启动、停止、窗口关闭及存储失败。浏览器验证主页选题、桌面/移动布局和本地拦截的批量表单；不为测试向真实 YOJ 重复发出评测。完整回归及暂存树脱敏/一致性检查后，以 Scorpascal 身份推送 main 并核对同 SHA 的 Pages。
